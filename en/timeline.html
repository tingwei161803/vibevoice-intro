Development timeline

From the first TTS announcement to ASR landing in Hugging Face Transformers.

  1. Aug 2025

    TTS announced

    The original VibeVoice text-to-speech model debuts; the work is later accepted as an ICLR 2026 Oral.

  2. Sep 2025

    TTS code removed

    The code is pulled over misuse concerns; the model weights remain available on Hugging Face.

  3. Dec 2025

    Realtime-0.5B expansion

    An experimental speaker expansion lands for the lightweight real-time model.

  4. Jan 2026

    ASR-7B released

    The 7B speech-recognition model arrives with 60-minute single-pass transcription.

  5. Mar 2026

    ASR in Transformers

    VibeVoice-ASR is integrated into Hugging Face Transformers for easy use.
